# XenoForge's logo

A ring of light in four quadrants around an anvil struck into a spark: the
forge that turns a disc into native code. Original artwork of this project,
under the project's license; it is not, and does not imitate, any console
maker's mark.

- `xenoforge.svg`: the mark, the source of everything else here.
- `xenoforge-<size>.png`: the mark at 16 to 512 pixels, transparent.
- `xenoforge.ico`: Windows icon (16 to 256 pixels) for the executables.
- `xenoforge-wordmark-dark.png`, `xenoforge-wordmark-light.png`: the mark
  with the name, for dark and light backgrounds.

Colors: greens `#b8f25a`, `#5fd22c`, `#139a1b`; the disc `#1c2a1f` to
`#070b08`; the anvil `#f4fbef` to `#b9c9b5`.

# HLSL effects for the translator's corpus

Written for XenoForge, not taken from any game. Compiled for the Xbox 360
with XNA Game Studio 4.0's content pipeline (`tools/xna/`), which carries
Microsoft's Xbox 360 shader compiler, so their microcode is what that
compiler makes: the control flow, constants and fetches games get. Each
file goes after what the games' shaders seen so far lack.
